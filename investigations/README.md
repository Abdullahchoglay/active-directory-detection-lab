# Investigations

Investigation reports will use evidence-backed conclusions and distinguish benign test activity from genuinely suspicious behavior.

Suggested sections:

- Executive summary
- Scenario and marker
- Timeline
- Local evidence
- Wazuh evidence
- Identity and authentication context
- Process or directory context
- MITRE ATT&CK mapping
- Analyst assessment
- Containment or cleanup performed
- Limitations

No report should claim a live alert unless the alert was actually observed.
